# Phrasebook (내 문장 모음)

고객 문의에 같은 안내 문장을 자주 붙여 넣는 사람을 위한 크롬 확장 프로그램이에요.
웹페이지에서 문장을 드래그하고 우클릭해서 저장해 두었다가, 단추를 눌러 카드를 누르면 복사돼요.

- 저장한 문장은 **내 크롬 안에만** 저장돼요. 바깥 서버로 보내지 않아요.
- 최대 30개, 한 문장은 500자까지예요.
- 필요한 권한은 우클릭 메뉴(`contextMenus`)와 저장(`storage`) 두 가지뿐이에요.

## 쓰는 방법
1. 웹페이지에서 저장할 문장을 드래그해요.
2. 우클릭해서 **내 문장 모음에 저장**을 눌러요.
3. 아이콘을 눌러 팝업을 열고, 카드를 누르면 복사돼요.

우클릭이 안 되는 페이지에서는 팝업의 **새 문장**으로 직접 추가할 수 있어요.
30개가 가득 차면 자동으로 지우지 않고, 지울 문장을 직접 고르게 해요.

## 크롬에 설치하기
1. 이 저장소를 내려받아 압축을 풀어요. (Code → Download ZIP)
2. 크롬 주소창에 `chrome://extensions`를 입력해요.
3. 오른쪽 위 **개발자 모드**를 켜요.
4. **압축해제된 확장 프로그램을 로드합니다**를 눌러요.
5. 이 저장소의 `extension` 폴더를 골라요.

## 폴더 구성
| 위치 | 하는 일 |
|---|---|
| `extension/manifest.json` | 이름, 버전, 권한, 팝업 파일 이름 |
| `extension/background.js` | 우클릭 메뉴를 만들고, 고른 문장을 저장해요 |
| `extension/popup.html`, `extension/popup.js` | 저장한 문장을 카드로 보여 주고 복사·추가·수정·삭제를 해요 |
| `extension/icons/` | 확장 프로그램 아이콘 |
| `prototype/flow-test.html` | 크롬에 설치하지 않고 사용자 흐름과 예외 상황을 눌러 보는 시험용 화면 |

`prototype/flow-test.html`은 파일을 더블클릭해서 열면 돼요. 화면 기획표 탭에 상황별 알림 문구가 정리돼 있어요.

## 알아 둘 점
- 저장 직후 팝업 자동 열기는 크롬 버전이나 창 상태에 따라 막힐 수 있어요. 막혀도 아이콘 표시와 다음에 여는 팝업의 알림으로 알 수 있어요.
- 크롬 내부 페이지와 웹 스토어에서는 크롬이 우클릭 메뉴를 막아요.
- 시크릿 창에서 쓰려면 `chrome://extensions`에서 이 확장 프로그램의 시크릿 모드 허용을 켜 주세요.
