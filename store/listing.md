# 크롬 웹 스토어 등록 문구 (한국어)

기준 버전: 1.1.0 · 언어: 한국어만 · `[확인 필요]`는 직접 정해야 하는 항목

## 1. 앱 이름 (최대 75자)
**내 문장 모음 (Phrasebook)**

- 스토어 표시 이름은 manifest.json의 `name`을 그대로 써요. 지금은 `내 문장 모음`이라서, 위 이름으로 정하면 manifest도 맞춰야 해요. [확인 필요]

## 2. 패키지 요약 (최대 132자)
웹페이지의 문장을 드래그하고 우클릭해 저장해 두었다가, 카드를 눌러 바로 복사하는 문장 보관함이에요. 저장한 문장은 내 크롬 안에만 남아요.

## 3. 상세 설명 (플레인 텍스트, 그대로 붙여 넣기)

```
같은 안내 문장을 하루에도 몇 번씩 복사해 붙여 넣고 계신가요?

고객 문의에 답하거나, 메일을 쓰거나, 게시글에 댓글을 달다 보면 "문의해 주셔서 감사합니다", "환불은 결제 후 7일 이내에 가능합니다"처럼 늘 쓰는 문장이 생겨요. 이런 문장이 메모장, 문서, 예전 메일 여기저기에 흩어져 있으면 찾는 데만 시간이 걸려요.

내 문장 모음(Phrasebook)은 웹페이지에서 본 문장을 드래그해서 한 번에 모아 두고, 필요할 때 카드를 눌러 바로 복사하는 문장 보관함이에요. 별도의 문서나 메모 앱을 열지 않아도 지금 보고 있는 화면에서 끝나요.

■ 이렇게 써요
1. 저장할 문장을 드래그해요.
2. 마우스 오른쪽 버튼을 눌러 '내 문장 모음에 저장'을 선택해요.
3. 확장 프로그램 아이콘을 열면 저장한 문장이 카드로 모여 있어요.
4. 붙여 넣고 싶은 카드를 누르면 복사돼요. 입력창에서 붙여 넣기(Ctrl+V 또는 Cmd+V)만 하면 끝이에요.

■ 주요 기능
· 우클릭 저장: 웹페이지에서 드래그한 문장을 메뉴 한 번으로 저장해요. 저장하면 아이콘에 표시가 뜨고, 팝업에 알림이 나와요.
· 직접 입력: 팝업의 '새 문장'으로 직접 써서 추가할 수 있어요. 우클릭이 막힌 페이지에서도 쓸 수 있어요.
· 누르면 복사: 카드를 누르면 복사되고, '복사했어요' 알림과 함께 해당 카드에 '복사됨' 표시가 나와요.
· 수정과 삭제: 저장한 문장을 고치거나 지울 수 있어요. 실수로 지웠다면 '되돌리기'로 바로 살릴 수 있어요.
· 검색: 저장한 문장이 6개 이상이 되면 검색창이 나타나요.
· 전체 지우기: 확인 창을 거쳐 한 번에 비울 수 있어요.
· 같은 문장 방지: 직접 입력하거나 고칠 때 이미 있는 문장이면 안내해 드려요.
· 밝은 화면, 어두운 화면 지원

■ 한도와 가득 찼을 때
· 문장은 최대 30개, 한 문장은 최대 500자까지 저장할 수 있어요.
· 28개를 넘기면 곧 가득 찬다고 미리 알려 드려요.
· 30개가 가득 찬 상태에서 새 문장을 저장하면, 오래된 문장을 자동으로 지우지 않아요. 저장하려는 문장과 지울 후보 목록을 보여 주고, 직접 고른 문장만 지워요. 가장 오래된 문장이 미리 골라져 있어서 한 번에 저장할 수 있고, 저장하지 않고 닫을 수도 있어요. 저장한 뒤에도 '되돌리기'가 가능해요.

■ 내 문장은 내 크롬 안에만 있어요
· 저장한 문장은 브라우저 저장소(내 크롬 안)에만 보관돼요.
· 바깥 서버로 보내지 않아요. 개발자도 내 문장을 볼 수 없어요.
· 로그인, 회원가입, 광고, 사용 기록 수집이 없어요.
· 필요한 권한은 우클릭 메뉴와 저장, 딱 두 가지예요. 웹페이지의 내용을 읽거나 바꾸지 않아요.

■ 알아 두세요
· 크롬 내부 페이지와 크롬 웹 스토어 화면에서는 크롬이 우클릭 메뉴를 막아요. 이때는 팝업의 '새 문장'으로 직접 추가해 주세요.
· 저장 직후 팝업이 자동으로 열리지 않을 수 있어요. 그래도 아이콘의 표시와, 다음에 여는 팝업의 알림으로 저장 결과를 확인할 수 있어요.
· 시크릿 창에서 쓰려면 chrome://extensions에서 이 확장 프로그램의 시크릿 모드 허용을 켜 주세요.
· 크롬을 지우거나 브라우저 데이터를 삭제하면 저장한 문장도 함께 사라져요.

문의: 팝업 하단의 Email 링크
```

## 4. 전용 목적 (한 문장)
웹페이지에서 선택한 문장을 저장해 두고, 팝업에서 눌러 복사할 수 있게 하는 개인용 문장 보관함이에요.

## 5. 권한 사용 이유
| 권한 | 이유 (한 문장) |
|---|---|
| `contextMenus` | 사용자가 문장을 드래그하고 우클릭했을 때 '내 문장 모음에 저장' 메뉴를 보여 주기 위해 필요해요. |
| `storage` | 사용자가 저장한 문장과 수정·삭제 내용을 사용자의 크롬 안에 보관하기 위해 필요해요. |

- 호스트 권한: 없음 (웹페이지 내용을 읽거나 바꾸는 스크립트를 넣지 않아요)
- 원격 코드 사용: 아니요 (모든 코드가 패키지 안에 있어요)

## 6. 개인정보 보호 탭 답변 초안
- 수집하는 사용자 데이터: 사용자가 직접 저장한 문장은 사용자의 기기 안에만 저장되고 개발자에게 전송되지 않음. 스토어 양식에서 어느 항목에 체크할지는 질문을 보고 확정 [확인 필요]
- 데이터 사용 인증 3가지: 승인된 사용 외에 판매·사용하지 않음 / 목적과 무관하게 사용하지 않음 / 신용도 판단에 사용하지 않음 → 모두 해당 사항 없음으로 인증 가능
- 개인정보처리방침 URL: [확인 필요] (아직 없음)

- [ ] 개인정보처리방침 URL 준비
