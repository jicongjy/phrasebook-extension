# 개인정보 보호 탭 입력 내용 (크롬 웹 스토어 개발자 대시보드)

기준: 내 문장 모음(Phrasebook) 1.1.0 · 권한 `contextMenus`, `storage` · 호스트 권한 없음 · 원격 코드 없음
각 입력란은 1,000자 이내예요. 아래 문구는 그대로 붙여 넣으면 돼요.

---

## 1. 전용 목적 설명 (1,000자 이내)
내 문장 모음(Phrasebook)은 사용자가 웹페이지에서 선택한 문장을 저장해 두고, 확장 프로그램 팝업에서 카드를 눌러 바로 복사할 수 있게 하는 개인용 문장 보관함입니다. 저장한 문장은 사용자의 브라우저 안에만 보관되며 외부 서버로 전송되지 않습니다.

## 2. 권한 요청 이유 (항목마다)

### contextMenus 사용 근거
사용자가 웹페이지에서 문장을 드래그하고 우클릭했을 때 '내 문장 모음에 저장' 메뉴를 보여 주기 위해 사용합니다. 사용자가 이 메뉴를 직접 눌렀을 때만 선택한 문장이 저장되며, 메뉴를 누르지 않으면 어떤 내용도 읽거나 저장하지 않습니다.

### storage 사용 근거
사용자가 저장한 문장(최대 30개)과 문장의 수정·삭제 내용, 사용 안내를 이미 봤는지 여부를 사용자의 브라우저 안(chrome.storage.local)에 보관하고 팝업에서 다시 불러오기 위해 사용합니다. 이 데이터는 외부로 전송되지 않으며, 사용자가 문장을 지우거나 확장 프로그램을 제거하면 함께 삭제됩니다.

### 호스트 권한 / 기타 권한
요청하지 않습니다. 웹페이지에 스크립트를 넣거나 페이지 내용을 읽지 않고, 우클릭 메뉴로 사용자가 고른 문장만 다룹니다. (호스트 권한 입력란은 나타나지 않아요.)

## 3. 원격 코드 사용
**아니요.** 실행하는 모든 코드(manifest.json, background.js, popup.html, popup.js)가 패키지 안에 들어 있고, 외부 주소의 코드를 불러오거나 실행하지 않습니다.

## 4. 사용자 데이터 사용

### 4-1. 수집하는 사용자 데이터 (체크 항목)
이 확장 프로그램은 사용자 데이터를 기기 밖으로 보내지 않으므로 **모든 항목을 체크하지 않아요.**

| 항목 | 체크 | 이유 |
|---|---|---|
| 개인 식별 정보 | 안 함 | 이름, 이메일 등을 받지 않음 |
| 건강 정보 | 안 함 | 받지 않음 |
| 금융 및 결제 정보 | 안 함 | 받지 않음 |
| 인증 정보 | 안 함 | 로그인이 없음 |
| 개인 커뮤니케이션 | 안 함 | 받지 않음 |
| 위치 | 안 함 | 받지 않음 |
| 웹 기록 | 안 함 | 방문 주소와 기록을 받지 않음 |
| 사용자 활동 | 안 함 | 클릭·입력 기록을 모으지 않음 |
| 웹사이트 콘텐츠 | 안 함 | 사용자가 고른 문장을 기기 안에만 저장하고 전송하지 않음 |

[확인 필요] 양식이 '기기 안에만 저장'도 수집으로 묻는다면 '웹사이트 콘텐츠'만 체크하고, 개인정보처리방침의 "전송하지 않음"을 근거로 해요.

### 4-2. 데이터 사용 인증 (3개 모두 체크)
- [x] 승인된 사용 사례 외에는 사용자 데이터를 제3자에게 판매하거나 전송하지 않습니다.
- [x] 단일 목적과 관련 없는 목적으로 사용자 데이터를 사용하거나 전송하지 않습니다.
- [x] 신용도 판단이나 대출 목적으로 사용자 데이터를 사용하거나 전송하지 않습니다.
