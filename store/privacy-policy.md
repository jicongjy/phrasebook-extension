# 내 문장 모음(Phrasebook) 개인정보처리방침

시행일: 2026년 11월 19일

## 1. 한 줄 요약
내 문장 모음은 사용자가 저장한 문장을 사용자의 크롬 안에만 보관하고, 바깥 서버로 보내지 않아요.

## 2. 다루는 정보
| 정보 | 언제 | 어디에 | 목적 |
|---|---|---|---|
| 사용자가 저장한 문장 (우클릭 저장 또는 직접 입력) | 사용자가 저장을 눌렀을 때 | 사용자의 브라우저 저장소(chrome.storage.local) | 팝업에 카드로 보여 주고 복사하기 위해 |
| 저장 시각, 문장 번호 | 문장을 저장할 때 | 같은 저장소 | 목록 정리와 오래된 문장 표시를 위해 |
| 처음 사용 안내를 봤는지 여부 | 안내를 열었을 때 | 같은 저장소 | 안내를 반복해서 보여 주지 않기 위해 |

## 3. 다루지 않는 정보
이름, 이메일, 전화번호, 위치, 방문한 웹페이지 주소와 기록, 결제 정보를 받지 않아요. 웹페이지의 내용을 읽는 코드도 없고, 사용자가 우클릭 메뉴로 고른 문장만 저장해요. 로그인과 회원가입이 없어요.

## 4. 외부로 보내지 않아요
- 저장한 문장을 개발자나 제3자에게 전송하지 않아요.
- 광고, 분석 도구, 외부 라이브러리를 쓰지 않아요.
- 제3자에게 제공하거나 판매하지 않아요.

## 5. 보관과 삭제
- 문장은 최대 30개까지 사용자의 기기에 남아요.
- 사용자는 팝업에서 문장을 하나씩 지우거나 '모두 지우기'로 비울 수 있어요.
- 확장 프로그램을 제거하거나 브라우저 데이터를 지우면 저장한 문장도 함께 삭제돼요.
- 개발자는 사용자의 문장에 접근할 수 없어서 대신 지워 드릴 수 없고, 사용자가 직접 지우면 돼요.

## 6. 권한을 쓰는 이유
- `contextMenus`: 우클릭 메뉴에 '내 문장 모음에 저장'을 보여 주기 위해
- `storage`: 저장한 문장을 사용자의 브라우저 안에 보관하기 위해

## 7. 아동 정보
아동의 정보를 따로 받지 않아요. 어떤 사용자의 정보도 받지 않아요.
